# Interactive Registration Form

A responsive and interactive registration form built as part of my **Front-End Development Internship at Codveda Technologies**.

The project focuses on creating a user-friendly form with real-time validation, password strength feedback, and clear error messages.

## Features

- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Form Validation:** Validates full name, email address, and phone number.
- **Password Validation:** Checks password length, uppercase and lowercase letters, numbers, and special characters.
- **Password Strength Indicator:** Displays password strength as the user types.
- **Show/Hide Password:** Allows users to toggle password visibility.
- **Confirm Password:** Checks whether both password fields match.
- **Terms and Conditions:** Requires users to accept the terms before submitting.
- **Real-Time Feedback:** Displays validation errors and success messages.
- **Accessibility:** Includes labels, keyboard focus indicators, and accessible feedback messages.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Fill in the form and test the validation features.

## Note

This is a front-end practice project. Form validation is performed in the browser, and no account is actually created or submitted to a server.
